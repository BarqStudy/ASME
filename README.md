# ASME
CLUB ENGINEER

منصة نادي الهندسة الميكانيكية بجامعة نجران، الفرع الطلابي لـ ASME.

## التشغيل

يتطلب المشروع Node.js 24 أو أحدث. قاعدة البيانات SQLite مدمجة في Node.js، ولا يحتاج المشروع إلى تثبيت حزم خارجية.

```sh
npm start
```

يستمع الخادم افتراضيًا على المنفذ 3000. يدعم المتغيرات التالية:

| المتغير | الاستخدام |
| --- | --- |
| `PORT` | منفذ الخادم. |
| `ASME_ADMIN_PASSWORD` | كلمة مرور الإدارة، 12 محرفًا على الأقل. أضفها في إعدادات أسرار الاستضافة. عند غيابها يتعطّل دخول الإدارة. |
| `ASME_CONTACT_EMAIL` | البريد الرسمي للنادي، لإظهار رابط البريد الإلكتروني بجانب نموذج التواصل. |
| `ASME_DATA_DIR` | مجلد قاعدة البيانات. الافتراضي `data/`. استخدم وحدة تخزين دائمة واحتفظ بنسخة احتياطية لبيانات العضوية والحضور. |

بعد ضبط كلمة مرور الإدارة وإعادة تشغيل الخادم، افتح «لوحة الإدارة» من تذييل الصفحة. من اللوحة يمكن مراجعة العضويات، وإدارة اللجان والبنرات والفعاليات والأخبار والإنجازات، ومراجعة رسائل التواصل. تظهر رسائل النموذج في اللوحة ويمكن الرد عليها عبر البريد.

## الدورات والمعسكرات والشهادات

أضف فعالية وحدّد حقول الزوار وأدنى نسبة حضور لإصدار الشهادة. العضو المقبول يستخدم بيانات عضويته للتسجيل. بعد الفعالية أدخل نسبة حضور كل مسجّل في تبويب «الحضور». حمّل صورة القالب واختر موضع الاسم بالنقر عليها أو بتعديل الإحداثيات، واضبط الخط واللون والحجم من المعاينة. يسترجع المسجّل شهادته بالبريد ورمز التسجيل، أو من حسابه إن سجّل بعضويته، ويمكنه طباعتها أو حفظها PDF من المتصفح.

البريد الجامعي يُشتق من رقم الطالب. قبول العضوية يدوي في لوحة الإدارة ولا يوجد تحقق آلي بالبريد الجامعي في هذه النسخة.

## الأصول البصرية

صورة البنر الرئيسي مولّدة للمشروع. يحتوي `public/assets/logo.webp` على نسخة أُعيد إنشاؤها من الشعار المرفق. لتطبيق خط ثمانية، ضع نسختي الخط الأصليتين `thmanyahserifdisplay-Regular.otf` و`thmanyahserifdisplay-Bold.otf` في `public/assets/` ثم أعد تشغيل الخادم. تدعم الواجهة خطًا عربيًا بديلًا عند غياب الملفات.

البنرات المرفوعة تُعرض بتصميم واحد مرن. استخدم نسبة 16:9 مع مساحة آمنة حول العناصر الأساسية لاستيعاب القص على الهواتف.
